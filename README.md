# Arcaea_guessc_helper
针对Arcaea guessc猜曲绘玩法的辅助工具。随机截取一张曲绘的一部分，复制进入guessc工具，自动完成完整曲绘识别。

一、关于使用
1.首先完整下载并解压压缩包

2.双击ArcaeaGuessc.exe打开程序
<img width="1013" height="724" alt="图片" src="https://github.com/user-attachments/assets/36dfe3e6-2863-407f-a818-51e839ef5f41" />

3.复制截取的图片，点击左上方“粘贴曲绘”按钮，即可自动识别
<img width="1020" height="723" alt="图片" src="https://github.com/user-attachments/assets/3bc5edf1-99aa-4c2f-b3cd-bd5f4e853378" />


二、关于曲库
曲库资源在resources目录下，包含images和songlist.json
songlist.json包含 songid、title、artist、image等曲目信息；
images是曲绘库，包含arc7.0.260全部曲绘图片。


三、曲库更新
Arcaea每次更新幅度较小，推荐手动更新：
1.将相应新曲曲绘粘贴至images目录下，图片格式不限；
2.再编辑songlist.jaon，补充曲目的标题、曲师、路径等信息；
3.再重新打开程序即可，每次更新曲库后首次加载可能用时较长。
